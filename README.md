# AstroAtlas

A React web application that displays planetary data fetched from an external API.
Built collaboratively as a capstone project for TS Academy.

## Running Locally
1. Clone the repo
2. Copy `.env.example` to `.env` and fill in the API URL and FORM ENDPOINT
3. Run `npm install`
4. Run `npm run dev`
